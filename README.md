# TvLauncher 1.0 (`tv.launcher.private`)

Лаунчер для Android TV в стиле Android/Google TV Home, без сервисов Google.
Вкладки «Главная» и «Приложения», меню по долгому нажатию OK, режим «Переместить»,
панель «Выберите приложение» и профили с настройками (всё сохраняется сразу).

## Сборка на GitHub
1. Создайте репозиторий и загрузите в него содержимое этой папки (вместе с `.github`).
2. Откройте вкладку **Actions** → **Build APK** → **Run workflow** (или просто сделайте push в `main`).
3. Готовый APK: артефакт `TvLauncher-1.0` внизу страницы запуска (файл `app-release.apk`).
   APK подписан отладочным ключом, поэтому ставится сразу.

Локально: `./gradlew assembleRelease` (JDK 17 + Android SDK 34).

## Управление
- OK — открыть приложение; удерживать OK (или кнопка Menu) — меню: Открыть, Переместить,
  Добавить/Удалить из избранного, О приложении, Удалить.
- «Переместить»: стрелки двигают карточку, OK или Назад — готово.
- Серый круг с буквой в шапке (или значок TvLauncher в списке приложений) — профили и настройки.
- Шестерёнка — системные настройки Android TV.

## Профили
У каждого профиля свои: имя и аватар (картинка или цвет + первая буква), порядок значков и избранное,
фон (картинка / GIF / видео), звук (вкл/выкл, громкость, звук видео или свой аудиофайл,
«играть в других приложениях»), прозрачность значков, свои картинки значков,
показ/скрытие приложений, скрытие значка лаунчера.
Новые приложения, для которых порядок не задан, ставятся в конец.

Приложения без ТВ-значка (обычные Android-приложения) тоже показываются: для них рисуется
карточка с иконкой и названием.

## Примечания
- Выбор файла: системный выбор документов; если его на ТВ нет — встроенный файловый менеджер
  (понадобится выдать доступ к файлам). Выбранные файлы копируются в хранилище лаунчера.
- GIF-анимация работает на Android 9+ (на старых показывается первый кадр).
- Звук «в других приложениях» держит служба переднего плана с уведомлением.
- Чтобы лаунчер стал главным: Настройки → Приложения → Приложения по умолчанию → Главный экран
  (на Google TV может понадобиться ADB-команда для отключения штатного лаунчера).
